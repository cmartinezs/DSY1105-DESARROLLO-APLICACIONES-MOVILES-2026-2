# Lab Semana 4 · Mi primera app Android

**Curso:** DSY1105  
**Semana:** 4  
**Objetivo:** crear, ejecutar, modificar y verificar una aplicación Android mínima con Kotlin usando Android Studio.

## Prerrequisitos

- Android Studio instalado y operativo.
- SDK disponible.
- Emulador configurado o dispositivo físico habilitado para desarrollo.
- Fundamentos Kotlin de semanas anteriores.

> Si el entorno no está listo, registra el bloqueo exacto. No reemplaces la evidencia de ejecución con una captura de código.

## Paso 1 · Crear el proyecto

1. Abre Android Studio.
2. Selecciona una plantilla mínima apropiada para iniciar una aplicación Android.
3. Usa un nombre identificable para el proyecto, por ejemplo `MiPrimeraApp`.
4. Usa Kotlin como lenguaje cuando la plantilla lo permita/configure.
5. Revisa la ubicación del proyecto y la versión mínima antes de confirmar.
6. Espera a que termine la sincronización/build inicial.

### Checkpoint 1

Verifica que:

- el proyecto abre sin error bloqueante;
- puedes identificar el módulo `app`;
- Android Studio no sigue ejecutando una sincronización fallida.

## Paso 2 · Reconocer la estructura

Localiza:

1. código Kotlin principal generado por la plantilla;
2. carpeta de recursos;
3. `AndroidManifest.xml`;
4. configuración Gradle del proyecto/módulo;
5. configuración de ejecución y dispositivo.

### Checkpoint 2

Explica con tus palabras para qué sirve cada elemento. No avances si sólo puedes localizarlo pero no describir su propósito general.

## Paso 3 · Primera ejecución

1. Selecciona un emulador o dispositivo.
2. Ejecuta la aplicación.
3. Espera a que el proceso complete build, instalación y arranque.
4. Observa el resultado.

### Checkpoint 3

Debes tener evidencia de una app abierta en el dispositivo/emulador.

Si falla, identifica la etapa:

- build;
- instalación;
- arranque/runtime;
- dispositivo/emulador.

## Paso 4 · Primera modificación

1. Modifica un texto o comportamiento mínimo visible.
2. Guarda los cambios.
3. Vuelve a ejecutar.
4. Comprueba que el cambio aparece.

### Checkpoint 4

Registra:

- archivo modificado;
- cambio realizado;
- resultado esperado;
- resultado observado.

## Paso 5 · Usar Kotlin conocido

Agrega una variación mínima usando un concepto ya aprendido: variable, función o condicional. No incorpores todavía arquitectura, navegación compleja ni persistencia.

### Checkpoint 5

Puedes explicar qué parte es lógica Kotlin y qué parte pertenece al entorno Android/recursos.

## Paso 6 · Cierre

Responde brevemente:

1. ¿Qué diferencia principal encontraste entre ejecutar Kotlin de consola y una app Android?
2. ¿Qué rol cumple Gradle?
3. ¿Dónde buscarías primero un error de compilación?
4. ¿Qué evidencia demuestra que tu app realmente se ejecutó?
5. ¿Qué deuda técnica o de configuración quedó pendiente?

## Evidencia a conservar

- proyecto compilable;
- evidencia de ejecución;
- modificación visible;
- respuestas de cierre;
- DevLog Semana 4.
