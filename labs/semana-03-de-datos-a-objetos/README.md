# Laboratorio · Semana 03 · De datos sueltos a objetos

## Objetivo
Conectar colecciones, POO y control de errores mediante un gestor de actividades neutral y autocontenido.

## Resultado esperado
Programa Kotlin que parte con datos simples y evoluciona hacia clases, objetos, colecciones de objetos y manejo explícito de errores.

## Contenidos relacionados
Colecciones, clases, objetos, propiedades, métodos, encapsulamiento, herencia/polimorfismo cuando corresponda y control de errores.

## Conocimientos previos
Fundamentos Kotlin y colecciones de Semanas 01–02.

## Dependencia de laboratorios anteriores
**Ninguna obligatoria.** El laboratorio es independiente; los labs previos sólo aportan práctica acumulada.

## Secuencia
1. [Colecciones y deuda de modelado](./01-colecciones-y-deuda-modelado.md)
2. [Clases y colecciones de objetos](./02-clases-y-colecciones-objetos.md)
3. [Herencia y polimorfismo](./03-herencia-y-polimorfismo.md)
4. [Errores y cierre](./04-errores-y-cierre.md)

## Criterio de finalización
El estudiante se detiene en el último bloque realmente enseñado, conserva un programa ejecutable y puede explicar cada decisión. `data class`, `sealed class` y corrutinas no se fuerzan si todavía no han sido cubiertas.
