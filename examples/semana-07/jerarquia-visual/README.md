# Ejemplo 1 · Jerarquía visual

## Qué problema resolvemos
Si todo el contenido se ve igual, el usuario no sabe qué leer primero.

La jerarquía visual comunica importancia mediante roles tipográficos, agrupación y espaciado.

## Ejecuta y observa
Compara `headlineMedium`, `titleMedium` y `bodyMedium`. Observa también cuánto espacio hay entre bloques y cuánto dentro de cada `Card`.

## Prueba tú
1. cambia todos los textos al mismo estilo y compara;
2. restaura los roles originales;
3. aumenta la separación entre tarjetas sin cambiar la separación interna.

**Pregunta clave:** ¿qué información debería entender el usuario en los primeros dos segundos?
