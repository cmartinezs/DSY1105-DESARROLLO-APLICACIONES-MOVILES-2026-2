Semana 06 · 14–19 septiembre

Arquitectura, MVVM y primera UI con Jetpack Compose

EP1 cerró el primer tramo. Desde ahora el foco cambia desde Kotlin de consola hacia una aplicación Android ejecutable, manteniendo la lógica separada de la interfaz.

1Comprende el nuevo modelo mental.
UI Compose, estado, ViewModel y lógica de dominio cumplen responsabilidades distintas.
2Crea y ejecuta un proyecto Android.
Reconoce MainActivity, el punto de entrada de Compose y verifica el entorno en emulador o dispositivo.
3Construye una pantalla Compose propia.
Text, Button, Column/Row, Modifier y MaterialTheme como base.
4Introduce estado y MVVM sólo cuando aporten.
La UI describe; el ViewModel coordina estado/comportamiento; la lógica no debe quedar incrustada en composables.
5Retoma PocketLog.
Primer checkpoint Android con UI Compose y separación básica UI/lógica.
