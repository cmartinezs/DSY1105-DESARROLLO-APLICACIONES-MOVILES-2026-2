# Ejercicios Semana 4 · Android Studio

Ejercicios breves para practicar el ciclo de trabajo del IDE. No sustituyen el laboratorio guiado.

## 1 · Mapa del proyecto

En un proyecto recién creado, localiza y anota la función general de:

- código Kotlin;
- `res`;
- `AndroidManifest.xml`;
- configuración Gradle;
- selector de dispositivo.

**Checkpoint:** puedes explicar cada elemento sin usar la frase “porque Android Studio lo necesita”.

## 2 · Cambio visible

Modifica un texto visible de la aplicación, ejecuta nuevamente y registra:

1. archivo modificado;
2. valor anterior;
3. valor nuevo;
4. evidencia del cambio en ejecución.

## 3 · Ciclo de error controlado

Introduce temporalmente un error sintáctico simple en Kotlin, ejecuta el build y observa el mensaje. Corrígelo y vuelve a ejecutar.

**Objetivo:** distinguir un error de compilación de un fallo del emulador/dispositivo.

## 4 · Cambio de lógica mínimo

Reutiliza una variable, función o condicional Kotlin ya aprendido para producir un resultado distinto visible o trazable en la aplicación.

No incorporar librerías externas ni arquitectura nueva.

## 5 · Explica el flujo

Dibuja:

```text
código Kotlin + recursos
→ Gradle/build
→ APK/app instalable
→ emulador/dispositivo
→ ejecución
```

Explica qué puede fallar en cada etapa con un ejemplo.
