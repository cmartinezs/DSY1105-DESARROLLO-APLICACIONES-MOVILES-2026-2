# Ejercicio · MetaVisual
Construye un contador de sesiones con botones + y Reiniciar; impide negativos; muestra "Meta alcanzada" a partir de 5. Comienza con `remember` y cambia sólo el mecanismo a `rememberSaveable`.

**Pruebas:** (1) suma tres y comprueba recomposición, (2) rota el teléfono y compara mecanismos, (3) cierra y vuelve a abrir sin asumir persistencia, (4) describe cuándo usarías DataStore.

**Entrega:** código breve, dos capturas, tabla de observaciones y DevLog. No agregues base de datos ni API de hardware. Responde por qué la restauración no sustituye persistencia.
