# Ejemplos · Semana 01

## Java ↔ Kotlin en paralelo

Ejemplo práctico para trabajar el puente inicial entre Java y Kotlin dentro del mismo proyecto IntelliJ.

👉 [Abrir ejemplo Java ↔ Kotlin](./java-kotlin-paralelo/README.md)

Incluye:

- proyecto Gradle mixto Java/Kotlin;
- `AppJava.java`;
- `AppKotlin.kt`;
- variables, inferencia de tipos y `val`/`var`;
- String templates;
- condicionales;
- funciones;
- introducción a null safety;
- actividad breve de cierre.
