# Semanas · DSY1105 Desarrollo de Aplicaciones Móviles

`semanas/` contiene el contenido curricular que debe enseñarse semana a semana. Es independiente de `labs/`, `examples/` y `proyecto-formativo/`.

## Contrato

Cada `semana-XX/` tiene un `README.md` que resume la semana, indexa las materias, explica el orden sugerido y enlaza ampliaciones cuando corresponde.

Las materias que requieran profundización adicional pueden usar una subcarpeta propia con su propio `README.md` índice.

`semanas/` responde **qué se enseña**. Los ejemplos ejecutables viven en `examples/`, los laboratorios en `labs/` y la evolución incremental de PocketLog en `proyecto-formativo/`.
