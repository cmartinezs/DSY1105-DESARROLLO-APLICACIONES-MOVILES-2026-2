# Documentación transversal

Este directorio funciona como índice de conocimientos y guías que atraviesan más de una semana de la asignatura.

El contenido específico de cada semana continúa viviendo en `semanas/semana-XX/`. Aquí solo se enlaza material que conviene reutilizar durante distintas experiencias de aprendizaje.

## Índice inicial

- [Semanas del curso](../semanas/README.md)
- Semana 01: guía comparativa Java ↔ Kotlin dentro de [`semanas/semana-01/`](../semanas/semana-01/)
- Semana 02: fundamentos de Kotlin dentro de [`semanas/semana-02/`](../semanas/semana-02/)

Este índice crecerá a medida que aparezcan conocimientos realmente transversales; no se duplicará contenido solo para llenar la carpeta.
