# PocketLog · Semana 06 · v0.6 · Android + Jetpack Compose

## Objetivo
Migrar la funcionalidad acumulada de v0.4 a una aplicación Android real, sin reemplazarla por una demo decorativa.

## Se trabaja
Android Studio, `MainActivity`, Compose, `Column`, `Row`, `Text`, `Button`, `OutlinedTextField`, `LazyColumn`, estado, `ViewModel` y separación UI/comportamiento.

No se trabaja aún Navigation Compose, Room/SQLite, REST, DI ni cámara.

## Resultado
La app permite ver registros, agregar título/categoría, completar, filtrar todos/pendientes/completados, ver contadores y recibir mensajes de validación.
