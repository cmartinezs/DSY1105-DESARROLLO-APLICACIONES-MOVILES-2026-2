# Checkpoints de PocketLog

Esta carpeta conserva **fotografías históricas estables** del proyecto formativo.

```text
checkpoints/
├── semana-02/
├── semana-03/
└── ...
```

Un checkpoint permite revisar cómo era PocketLog al cerrar un hito curricular. **No es el proyecto que continúa desarrollándose.**

El estado vivo está siempre en [`../pocketlog/`](../pocketlog/).

Reglas:

- una vez consolidado, un checkpoint no se modifica para incorporar contenido futuro;
- solo se crea cuando existe un hito formativo que vale la pena preservar;
- las semanas de evaluación no obligan a crear checkpoints artificiales;
- la guía de la semana debe indicar cuál fue el checkpoint resultante cuando corresponda.
