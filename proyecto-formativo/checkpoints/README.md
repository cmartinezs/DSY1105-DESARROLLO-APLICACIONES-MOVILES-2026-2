# Checkpoints de PocketLog

Aquí se conservan estados históricos estables del proyecto.

## Disponibles

- [Semana 01 · v0.1 · datos y funciones sueltas](./semana-01/)
- [Semana 02 · v0.2 · procedural con colecciones](./semana-02/)
- [Semana 03 · v0.3 · orientada a objetos](./semana-03/)

PocketLog existe desde Semana 01. Cada checkpoint muestra cómo **los mismos requerimientos** se implementan con las herramientas que el curso ya ha enseñado.

Un checkpoint no es el proyecto vivo. `../pocketlog/` contiene la versión actual y `data/weekly/semana-XX.yml` conserva la verdad sobre el avance real de la sección.
