# Históricos de PocketLog

Este índice registra los hitos históricos del proyecto formativo sin duplicar la base de código.

## Regla

Cada cierre semanal relevante debe registrar:

- semana;
- versión/hito;
- estado alcanzado;
- commit o tag Git asociado;
- observaciones de continuidad.

La recuperación de una versión anterior se realiza desde Git. Esta carpeta conserva únicamente el índice y metadatos del hito.
