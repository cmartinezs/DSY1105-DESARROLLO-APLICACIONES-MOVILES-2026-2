# PocketLog · Guía Semana 01 · v0.1 conceptual

PocketLog se introduce esta semana **sin comenzar todavía la implementación**.

## Objetivo

Que el estudiante entienda que durante el semestre una misma solución evolucionará junto con el contenido de la asignatura.

## Actividad

1. Identifica un problema simple que pueda representarse como registros o actividades.
2. Describe qué información mínima debería guardar cada registro.
3. Explica por qué inicialmente se trabajará en consola antes de construir una interfaz móvil.
4. Registra la expectativa: Kotlin primero; Android cuando el programa lo indique.

## No hacer todavía

- crear clases propias;
- diseñar arquitectura;
- usar Compose;
- crear base de datos;
- consumir APIs.

El producto de esta semana es **comprensión del proyecto longitudinal**, no código adelantado.
