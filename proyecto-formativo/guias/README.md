# Guías de PocketLog

Aquí están las instrucciones para avanzar PocketLog por semana.

## Disponibles

- [Semana 01 · v0.1 conceptual](./semana-01/)
- [Semana 02 · v0.2 procedural](./semana-02/)
- [Semana 03 · v0.3 orientada a objetos](./semana-03/)

Las guías explican **cómo avanzar**. El código que continúa evolucionando vive en `../pocketlog/`.

La regla es curricular: una guía puede describir el objetivo de una semana sin afirmar que toda la sección ya lo alcanzó. El avance real se registra en `../../data/weekly/`.
