# PocketLog · Semana 02 · v0.2

La sección cerró realmente en condicionales, ciclos y funciones básicas. **Las colecciones aún no se dan por cerradas.**

## Objetivo
Transformar el programa estático en una aplicación interactiva de consola sin adelantar `List`.

Conceptos: `while`, `when`, funciones, `readln`, `toIntOrNull`, validación y estado mutable simple.

## Pasos
1. menú;
2. ciclo `while`;
3. validar opción;
4. registrar/reemplazar el registro activo;
5. mostrar;
6. completar;
7. consultar estado;
8. salir.

La limitación de un único registro prepara la necesidad real de `MutableList` en Semana 3.
