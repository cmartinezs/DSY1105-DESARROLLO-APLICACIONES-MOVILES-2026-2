# 03 · Control de errores

1. Identifica una operación potencialmente inválida.
2. Valida previamente cuando sea suficiente.
3. Usa `try/catch` sólo cuando corresponda al objetivo didáctico y captura una excepción específica.

**Checkpoint:** prueba un caso válido y uno inválido; ambos deben producir un comportamiento entendible.
