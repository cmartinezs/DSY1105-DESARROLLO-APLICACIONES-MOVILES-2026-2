# 01 · De datos a objetos

1. Identifica datos que representan una misma entidad.
2. Crea una clase que agrupe propiedades relacionadas.
3. Construye al menos dos objetos.
4. Sustituye gradualmente estructuras paralelas por objetos.

**Checkpoint:** PocketLog ejecuta usando objetos y puedes explicar clase, objeto y propiedad.
